- (direction) Fast path selected: produce a deliberately simple architecture for a non-developer hackathon team, with assumptions explicit.
- (constraint) The product brief binds manual, per-source retrieval for the MVP; no scheduled scan; no authentication; public sources only; source failure must remain visible and retain last successful data.
- (decision) Use a modular monolith with ports-and-adapters: one Next.js application owns screens and server-side workflows; source adapters are replaceable inbound adapters; Supabase is the sole persistent store. This binds all MVP units and prevents separate frontends, backends, and source-specific data models.
- (decision) Use the current Next.js 16.3.3 Active LTS and Supabase’s official Next.js starter pattern, deployed on Vercel. The app’s lockfile pins all package versions. This prevents bespoke infrastructure and version drift.
- (decision) All changes to event, review, ranking, and source-health records go through server-side application actions; browser code never writes directly to the database. This prevents competing mutation paths and exposure of privileged database credentials.
- (assumption) For the unauthenticated demo, the deployed URL is shared only with the hackathon team. Before any wider access, add authentication and row-level access rules.
- (decision) A stable source event key identifies the same source appointment across retrievals; retrieval uses upsert semantics and never deletes historical event or review records. This prevents duplicate agenda items and lost review history.
- (decision) Each adapter returns either normalized candidate data or a structured source-health result. A failed adapter leaves previous data intact and surfaces a visible error; labelled fixtures may be selected for the demo. This prevents silent data loss and inconsistent failure handling.
- (decision) Editorial suggestions remain transparent rules plus stored aggregate feedback; they may order candidates but may not auto-reject or auto-approve an event. This preserves the human editorial gate.
