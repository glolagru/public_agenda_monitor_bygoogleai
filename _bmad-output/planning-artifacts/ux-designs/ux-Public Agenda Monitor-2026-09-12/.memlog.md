- (decision) Use a harmonious, user-friendly palette: calm blue for Candidate Events already present in the list and subtle orange for newly retrieved Candidate Events.
- (direction) Use a Jira-backlog-like interaction as inspiration for manual prioritisation: researchers drag and drop event rows into the desired priority order.
- (direction) The reference screenshot's dense tabular planning layout informs information density, but the UX should be clearer and more user-friendly.
- (decision) The landing page provides two role entries: Information Specialists (media documentarians) and Redaktion. Both open the same horizontal event-table view; only the heading differs, and the Redaktion view omits the release/approval button. For the first draft, remove comments. Each row leads with date and optional time, then event title, overarching topic, source name, direct source link, and all other defined fields; the approval button is the final column for Information Specialists.
